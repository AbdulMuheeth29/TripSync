You are building TripSync, an AI-powered group trip planning application. This is a fully functional web prototype demonstrating advanced AI product capabilities.

=== CORE PRODUCT ===
TripSync helps groups plan trips in minutes instead of hours by combining AI itinerary generation, collaborative decision-making, booking coordination, and expense tracking in one platform.

=== TECH STACK ===
- Frontend: React with Tailwind CSS
- Backend: Node.js/Express
- Database: SQLite (for prototype simplicity)
- AI: Anthropic Claude API (use environment variable ANTHROPIC_API_KEY)
- Authentication: Simple email-based auth (no passwords for demo)
- Real-time: Server-Sent Events or polling (not WebSockets for simplicity)
- Payments: Mock Stripe integration (UI only, no real charges)

=== FEATURES TO BUILD ===

**1. LANDING PAGE**
- Hero section: "Plan group trips in 10 minutes, not 10 hours"
- Problem/Solution breakdown
- Feature highlights with icons
- CTA: "Start Planning" button
- Pricing section: Free tier, $19/month Pro
- Footer with social links

**2. TRIP CREATION WIZARD**
- Step 1: Basic details (destination, dates, budget per person, group size)
- Step 2: Trip vibe selection (relaxing/adventure/foodie/nightlife - multi-select)
- Step 3: Accommodation preference (hotel/Airbnb/mix)
- Step 4: Dining preference (fine dining/casual/mix)
- Progress indicator showing steps
- AI generates trip immediately after submission

**3. AI ITINERARY GENERATION**
Use Claude API to generate a detailed 3-day itinerary with:
- Day-by-day breakdown
- Activities with time slots
- Restaurant recommendations with price estimates
- Hotel suggestions
- Transportation notes
- Total estimated cost per person
- Each item should have: name, description, time, location, price, category (flight/hotel/dining/activity)

CRITICAL: The AI prompt should include:
- Destination and dates
- Budget constraints
- Group size
- Trip vibe preferences
- Accommodation and dining preferences
- Request structured JSON output for easy parsing

**4. GROUP COLLABORATION**
- Trip organizer can invite others via email (just collect emails, no actual email sending)
- Simple "share link" that others can use to join
- Each trip member can:
  - View full itinerary
  - Comment on specific items
  - Vote (thumbs up/down) on activities
  - Suggest alternatives (text input)
- Show vote counts on each item
- Organizer can "lock itinerary" when ready

**5. BOOKING COORDINATION**
- Each itinerary item has a "Book Now" button with deep links to:
  - Flights: Google Flights (construct URL with destination/dates)
  - Hotels: Booking.com (construct URL with location/dates)
  - Restaurants: OpenTable or Google (construct search URLs)
- After booking, users can mark as "Booked" and upload confirmation screenshot
- Visual status tracker: Suggested → Booking in Progress → Booked
- Progress bar showing "5/12 items booked"

**6. EXPENSE TRACKING**
- During/after trip, anyone can log expenses:
  - "I paid $X at [place] for [# people]"
  - Select which group members participated
  - Auto-calculate split
- Running expense feed showing:
  - Who paid what, when
  - How much each person owes
  - Total spent vs budget
- Final settlement view:
  - "You owe Sarah $245" with mock Venmo button
  - Mark expenses as "settled"

**7. TRIP DASHBOARD**
Show all user's trips:
- Upcoming trips (status: Planning / Booked / In Progress)
- Past trips (Completed)
- Each trip card shows: destination, dates, # of people, budget, completion %

**8. DEMO DATA**
Include 2 sample trips pre-populated:
- "Miami Bachelorette Party" (6 people, $1500/person, May 15-18)
- "Austin Food Weekend" (4 people, $800/person, June 8-10)
Both should have full AI-generated itineraries

=== UI/UX REQUIREMENTS ===
- Modern, clean design with good spacing
- Mobile-responsive (works on phone/tablet/desktop)
- Use icons from Lucide React or Heroicons
- Color scheme: Primary (blue/teal), Secondary (coral/orange), Neutral (grays)
- Smooth transitions and hover states
- Loading states for AI generation (show spinner + "AI is planning your trip...")
- Empty states with helpful CTAs
- Toast notifications for actions (trip created, item booked, etc.)

=== DATABASE SCHEMA ===

**users**
- id, email, name, created_at

**trips**
- id, organizer_id, destination, start_date, end_date, budget_per_person, group_size, vibe, status, created_at

**trip_members**
- id, trip_id, user_id, role (organizer/member), joined_at

**itinerary_items**
- id, trip_id, type (flight/hotel/dining/activity), name, description, time, location, price_per_person, booking_status, category, day_number

**comments**
- id, item_id, user_id, content, created_at

**votes**
- id, item_id, user_id, vote_type (up/down), created_at

**expenses**
- id, trip_id, paid_by_user_id, amount, description, location, split_among (JSON array of user_ids), settled, created_at
